# Simple Brick Breaker

Implement an offline 2D browser brick-breaker game using vanilla HTML/CSS/JavaScript.
Do not use third-party libraries, external assets, network requests or build steps.

- Use a 640 × 480 canvas. Left/right arrow keys move the bottom paddle, which cannot leave the canvas.
- Arrange 3 rows of 6 bricks at the top. The ball should bounce appropriately off walls, the paddle and bricks.
- Each hit brick disappears and adds 10 points. Clearing all bricks wins.
- The ball falling through the bottom loses. Scoring stops after the game ends.
- Press P to pause/resume. Clicking “Restart” restores all bricks, the ball, paddle and score.
- Show score, status and controls. Draw graphics programmatically.
